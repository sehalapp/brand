Core Principles

Simple

Favor clean layouts, focused messaging, and generous spacing.

Confident

Use direct language and strong contrast to make decisions easy.

Consistent

Apply the same visual system across product, web, and print.

Logo Usage

Do

  • Keep generous clear space around the mark.
  • Use the primary logo on light backgrounds.
  • Use the reversed logo only on dark, solid fills.

Don't

  • Stretch, rotate, or crop the logo.
  • Add shadows, outlines, or decorative effects.
  • Place the mark on visually busy imagery.

Typography

Headings

Use a bold, modern sans-serif with tight line lengths.

Build trust with clarity.

Body

Keep supporting copy readable, calm, and easy to scan.

Clear guidance beats dense documentation every time.

Voice & Tone

Write like this

“Start with the essentials, then add detail only when it helps the reader act.”

Avoid this

Overly formal, vague, or jargon-heavy language that slows readers down.
