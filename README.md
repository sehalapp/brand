# Sehal brand

The source of truth for Sehal's visual identity.

**[Read the guidelines → sehalapp.github.io/brand](https://sehalapp.github.io/brand/)**

- [`BRAND.md`](./BRAND.md) — the written specification: logo construction and lockup
  metrics, the colour system with measured contrast ratios, typography, shape scale,
  pattern and border, and usage rules.
- [`index.html`](./index.html) — the visual board, published to GitHub Pages. Self-contained:
  fonts and geometry are embedded, so it renders offline from a single file.
- [`assets/`](./assets/) — production vectors. The wordmark is outlined, so these render
  correctly without the brand fonts installed.

## Fonts

| Role | Family | Licence |
|---|---|---|
| Brand & headlines | Vend Sans (Bloom Type) | SIL OFL 1.1 |
| Interface & body | Manrope (Mikhail Sharanda) | SIL OFL 1.1 |

Both are open-licensed and embedded in the guideline page.

## Using the logo

The mark's counter — the S — is **cut out**, so whatever sits behind it shows through.
Never place it on green, a mid-tone, a gradient or a photograph; see `BRAND.md` §2.5.
